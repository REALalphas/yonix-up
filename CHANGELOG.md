# Changelog

Changes are grouped by release. Until a tagged release is published, entries below describe the development version and do not imply a compatibility guarantee.

## Unreleased — 0.1.0 development

- Rust CLI, native GTK 4/libadwaita application and React browser panel sharing an operation service.
- NixOS module, desktop and headless packages, with flake and legacy configuration support.
- Serialized checks, builds, closure comparisons, activation, rollback and persistent operation logs.
- Explicit staged system cleanup and bounded, persistent Btrfs maintenance.
- Gateway-based peer management and signed Nix binary-cache configuration.
- Desktop and browser translations in 13 languages.
- Deterministic overlap handling in the daemon workflow test fixture, replacing a scheduling-dependent sleep.
- GitHub contribution and security guidance, issue and pull request templates, and explicit application and third-party license notices.

The original Bash implementation is retained in `old/` for historical reference.
