Yonix

Automated NixOS system management wrapper.

Installation

git clone https://github.com/yourusername/yonix.git
./yonix/yonix

Commands

update
Rebuild system configuration.
upgrade
Update flake inputs and rebuild.
clean
Garbage collect and optimize store.
trace
Rebuild with debug trace info.
build
Build new system (prompts for hostname).
dir
Show tracked config directory.
git-check
Check/pull git repository updates.
