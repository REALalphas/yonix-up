# AppShell — статус варианта в контекстном пикере

## Задача

Экран приложения Yonix показывает пикер управляемого хоста через `AppShell.context`
(«Managed host»). Требуется показать статус прямо в пикере: текущий вариант
дополняется текстом статуса из публичного `label` (`label + ' · ' + статус`),
остальные варианты — чистые имена хостов.

Установленная версия Alpha UI: **0.4.11** (официальный релиз, as-is).

Ограничение текущего API: у вариантов `AppShell.context.options` (и базовых
`Picker`/`Select`) только `value`, `label`, `disabled`. Отдельного слота под
статус, описание или тон варианта нет. Текст статуса внутри `label` читается
скринридером как часть имени и дублируется при раскрытии; скрывать его через
CSS, вмешиваться в DOM или подменять компонент в приложении запрещено правилами
`ALPHA_UI_AGENT_RULES.md`, поэтому использован штатный `label` без обходных
путей.

## Универсальное поведение

Контекстный пикер шапки показывает состояние выбранного варианта (готов,
выполняется, подключение, недоступен) отдельным от имени элементом:
в свёрнутом виде и в раскрытом списке. Имя хоста остаётся чистым доступным
именем; статус — отдельным описанием варианта. Неизвестное значение и пустой
список ведут себя как сейчас (см. `Picker.md`, `Headbar.md`).

## Предлагаемый API

Например, поле варианта в `AppShell.context.options` / `HeadBar.context.options`
/ `Picker.options` / `Select.options`:

```ts
options: { value: string; label: string; description?: string; disabled?: boolean }[]
```

`description` — короткий статус/подсказка, рендерится библиотекой рядом с
`label` (свёрнуто и в списке), не входит в доступное имя, наследует токены
темы. Отсутствие поля сохраняет текущий вид. Контракт одинаков для React/Qwik.

## Композиция и оформление

Рендер и оформление — на стороне библиотеки, без CSS-переопределений
в приложении. Статус использует существующие тона текста/индикаторы темы.

## Проверка

- Свёрнутый пикер: имя хоста + статус; раскрытый список: у текущего варианта
  виден статус, остальные — чистые имена.
- 320 и 1680 px, светлая/тёмная тема, длинные имена, скринридер (имя отдельно,
  статус отдельно), клавиатура, Escape, возврат фокуса.
- Неизвестное значение и пустой список не выбирают первый вариант молча.
- В приложении нет CSS-переопределений и подмен компонента.
