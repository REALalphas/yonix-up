# HeadBar — прямой Select для контекста

**Текущий статус: ожидается официальный API; прямое изменение библиотеки отменено.** Допустимы только официальные пакеты as-is. Никаких собственных выпусков, CSS/DOM-обходов или локальных замен; обсуждение необходимых изменений — только через ui-unspec.

## Задача

Целевой официальный выпуск — Alpha UI **0.4.11**, без патчей и локальных вариантов. В нём `HeadBar.context` внутри использует `Picker`; публичного способа выбрать прямой `Select` для этого места нет. Пользователь просит использовать именно `Select`, как в первом примере, без автоматически добавляемого placeholder.

## Требуемое поведение и API

Существующие `HeadBar.context` и `AppShell.context` сохраняют управляемые `value`, `options`, `label`, `disabled`, необязательный `placeholder` и событие `onContextChange` / `onContextChange$`. Реализация контекста использует публичный `Select variant="plain" popup="overlay"`; для известного выбранного значения без переданного placeholder не добавляется пустой пункт. Сохраняются доступное имя, уникальный id, выбор клавиатурой и закрытие по Escape. При пустом наборе вариантов контрол disabled; неизвестное значение не подменяется первым.

## Композиция и проверка

Расположение и оформление обеспечивает библиотечная шапка, без CSS-переопределений и подмены DOM в Yonix. Проверить React/Qwik, корень и подпапку, 320/1680 px, известное/неизвестное значение, пустой список, disabled, длинные названия и возврат фокуса. В DOM контекста есть `as-select-compact`, отсутствует обёртка `as-picker` и отсутствует пустой option при выбранном хосте.

### Уточнение deprecation

В проверенных официальных типах/каталоге 0.4.11 нет `@deprecated` ни у Select, ни у Picker. Требуется от сопровождающего Alpha UI явно указать актуальный компонент, пометить устаревший (если он устарел), описать миграцию и обеспечить поддержку актуального контрола через публичный API шапки. Агент самостоятельно deprecation не назначает и API библиотеки не меняет.
